# Source evidence matrix — 2026-10-15 (review only)

Status: **documentary research; zero provider credentials used, no production activation**. This is a **dated evidence snapshot**, not a market-data license grant or vendor SLA. Any field not verified on an official provider-owned source is **تأییدنشده**.

## Reading rules

1. "Instant / realtime" is a **vendor marketing/update-rate statement**, not an observed maximum end-to-end latency or bid/ask execution quote. Where timing of an actual source tick is not demonstrated, write **تأییدنشده**.
2. A vendor's right to let an API *be accessed* or *embedded in websites* must not be equated with a written right to store, bulk-republish, resell or redistribute raw/history data. Those rights are independently reviewed.
3. A sample response or free pricing page is not an entitlement for every instrument or price side. Raw **IRR→IRT /10** and **buy/sell** mappings require provider-verified evidence (see [Navasan adapter](../../packages/market-domain/src/adapters/navasan.mjs) and [P0 gate](../security/P0_RELEASE_GATES.md)).

Relevant prior repository evidence: [initial provider matrix](provider-source-matrix.md) at [main 381ba284](https://github.com/davoodmehraban89/VELYQOR/blob/381ba284d47f284f034afacc7d6cc41fc31af8f9/docs/data/provider-source-matrix.md); [provider transition policy, PR #22](https://github.com/davoodmehraban89/VELYQOR/blob/phase-1/gold-api-fallback/docs/data/iran-provider-transition-policy.md); [PR #30 on-demand catalog proof](https://github.com/davoodmehraban89/VELYQOR/blob/95e1389ba313c14652cf380182e5ea4b34007b3e/docs/operations/chartnova-compact-catalog-stage1-2026-10-15.md).

### Rights and latency decision

- **No domestic provider has documented, verified, no-cost public redistribution AND a tested bounded alert latency** in this review. Product activation and any bulk backfill are blocked until the relevant rights and quote-side semantics are confirmed.
- **No pair is declared cross-checked**. The secondary source, if later authorized, must match *instrument, market, side, unit, timestamp and quality*.
- Existing UI source **labels** ("Oanor/TGJU", "Gold API") are not sufficient to certify backend feed provenance for every displayed symbol; [PR #29 operational record](../operations/chartnova-production-progressive-loading-2026-10-15.md) and [PR #30 catalog documentation](https://github.com/davoodmehraban89/VELYQOR/blob/95e1389ba313c14652cf380182e5ea4b34007b3e/docs/operations/chartnova-compact-catalog-stage1-2026-10-15.md) describe divergent historical sources. Maintain **تأییدنشده** until a versioned Worker-source artifact and real response proof are available.

### Required vendor evidence before any single-provider pilot

Written/current official source confirmation of quote-side, IRR/IRT units and names for selected instrument; allowed public display, retention and derived alerts; actual quota/reset timezone and authentication limits; provider timestamp guarantees; a sanitized one-call sample; non-sensitive entitlement reference. Never put an API key or contract PDF containing credentials into this public repo.
